Options reference

Pass options as a table: saveinstance({ Decompile = false }). Names are case-insensitive. An unknown name prints a warning and is ignored.

You can also pass instances directly:

saveinstance(workspace.Castle)                         -- one model -> .rbxmx
saveinstance({ workspace.A, workspace.B })             -- several models
saveinstance(workspace.Castle, { FilePath = "Castle" }) -- instance + options

What to save​

OptionDefaultWhat it does
Mode"optimized""optimized" saves the services a place needs. "full" saves every saveable service. "scripts" keeps only branches that contain scripts ("script" is an alias).
ObjectfalseAn instance or list of instances to save as a model (.rbxmx). A service is saved as a folder. Object = game is the same as Mode = "full".
IsModelautomatictrue when Object is set. Set false to save Object as a place.
IgnoreList{ "CoreGui", "CorePackages" }Leave out instances and everything under them. Entries: an instance, a class name, or ClassName = { "Name", ... }. [instance] = false keeps the instance but drops its children.
IgnoreProperties{}Property names never to write, e.g. { "Transparency" }.
IgnoreNotArchivabletrueAlso save instances with Archivable = false. Set false to skip them.
RemovePlayerCharacterstrueLeave player characters out of Workspace.
NilInstancesfalseSave instances parented to nil (needs getnilinstances).
IsolateLocalPlayerfalseSave your Player's contents (PlayerGui, Backpack, ...) as folders.
IsolateLocalPlayerCharacterfalseSave your character.
IsolatePlayersfalseSave every Player as folders.
IsolateStarterPlayerfalseAlso save a copy of StarterPlayer's contents as folders.
ExtraInstances{}More instances to include.
SaveNotCreatablefalseSave instances of classes Studio cannot create (Player, PlayerGui, ...) as folders instead of leaving them out.

Extras from NilInstances, the Isolate* options and ExtraInstances go into ServerStorage.SaveInstance420, where they neither run nor render in Studio.

Scripts​

OptionDefaultWhat it does
DecompiletrueDecompile LocalScripts and ModuleScripts. false keeps the script instances with a note. Legacy: noscripts.
DecompileTimeoutautomaticSeconds per script: 30 for HTTP hooks such as Oracle, 10 for native decompilers. Failed scripts get one more try with three times as long. 0 = no limit. Legacy: timeout.
DecompileConcurrency16Requests in flight at once. Halves by itself when the provider says it is rate limited.
DecompileIgnore{ "TextChatService" }Save these scripts (and scripts under these instances) without decompiling them. Same entry format as IgnoreList.
IgnoreDefaultPlayerScriptstrueLeave out the engine's copies of PlayerModule, RbxCharacterSounds, ChatScript and BubbleChat, so Studio uses its working defaults.
ScriptCachetrueReuse decompiled sources for the rest of the session (same bytecode = same source). Legacy: scriptcache.
DecompileJoblessfalseOnly use cached sources; decompile nothing new.
SaveBytecodefalseAppend each script's bytecode (base64) to its source.
DecompilerFallbacktrueWhen the executor has no decompile(), send bytecode to the lua.expert API instead.
DecompilerApiUrllua.expertEndpoint for the fallback.
DecompilerApiGap0.12Seconds between fallback requests.
DecompilerNameautomaticLabel written into each source header. Detected automatically for Oracle, lua.expert, Konstant, Medal and native decompilers.

Properties​

OptionDefaultWhat it does
IgnoreDefaultPropertiestrueSkip properties equal to the class default. Makes files much smaller.
IgnoreSpecialPropertiesfalseNever call gethiddenproperty. Use only if it crashes your executor: union data and some hidden properties will be missing.
UseUGCValidationServicetrueUse UGCValidationService as a last-resort hidden-property reader.
TreatUnionsAsPartsfalseSave unions as Parts.
IgnoreSharedStringsfalseLeave out SharedString properties (union meshes, tags). Only for executors that crash on them.

Streaming​

OptionDefaultWhat it does
SetStreamingfalseRequest the map around you before saving. Alias: Streaming.
StreamingAreaSize10000Side of the square to sweep, in studs.
StreamingRadius512Grid spacing and settle radius, in studs.
StreamingCentercharacterVector3 center of the sweep.
StreamingSlices2Vertical layers per grid point.
StreamingPasses1Repeat the sweep (1 to 3).
StreamingPointsfalseYour own list of Vector3 points instead of a grid.
StreamingConcurrency4Requests in flight (max 8).
StreamingTimeout20Seconds per request.
StreamingChunkWait6Seconds to wait for a region's parts to stop changing.
StreamingSettleTime5Pause after the sweep for late arrivals.
StreamingMaxTimeautomaticOverall limit in seconds (max 3600).

Output and behavior​

OptionDefaultWhat it does
FilePathautomaticFile name without extension. Default: <place name> - <place id> - <UTC time>. Legacy: FileName.
CallbackfalseA function that receives the file in chunks instead of writing it.
ShowStatustrueShow the progress panel.
ReadMetrueAdd a README ModuleScript to ServerStorage.SaveInstance420.
DebugfalseWrite a log to SaveInstance420/debug <time>.log.
NeutralizeLightingfalseReset the live Lighting to clear midday before saving, so the file does not open dark or foggy.
SafeModefalseDisconnect from the server before writing the file and turn off 3D rendering while it runs. Streaming is skipped in SafeMode, since it needs the connection.
AntiIdletrueStop the 20-minute idle kick during long saves.
ShutdownWhenDonefalseClose the game when the save finishes.
YieldBudget8Milliseconds of work per frame. Raise for speed, lower if the game stutters.

Result​

saveinstance() returns a table:

{
    ok = true,
    path = "Blox Fruits - 2753915549 - 2026-11-23 19.25.00.rbxlx",
    bytes = 186310284,
    instances = 167018,
    scripts = { decompiled = 5005, cached = 907, failed = 5, server = 74, unavailable = 14, total = 6005 },
    decompiler = "Oracle",
    decompilerStopped = nil, -- or the provider's message when it stopped answering (expired key, quota)
    elapsed = 286.8,
    warnings = {},
}

On failure: { ok = false, error = "...", trace = "..." }. While a save runs, getgenv().SaveInstance420Status holds the current phase, done, total, bytes and elapsed.

Run statistics​

Run statistics for robloxscripts.com are not a saveinstance() option: they start when the script loads. Turn them off with getgenv().RSOPS_OFF = true before loading, or with rsops/optout.txt in your executor's workspace. See Run statistics and privacy.

Retired options​

DecompilePrepass, PrepassConcurrency, PrepassMaxTime, PrepassRateGap, PrepassApiUrl, PrepassMaxScripts, SaveCacheInterval, AlternativeWritefile, SharedStringOverwrite, NilInstancesFixes, NotCreatableFixes, Anonymous, StreamingPreview, StreamingRequireComplete, StreamingCancel, StreamingValidate and ExportObj are not part of 2.0. Retired names are ignored; the Prepass* ones are covered by the options under Scripts.
